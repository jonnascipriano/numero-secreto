# 🎮 Jogo do Número Secreto

Um jogo interativo e divertido construído para a web onde o objetivo do jogador é adivinhar um número secreto gerado aleatoriamente pelo sistema. 

Este projeto foi desenvolvido como parte dos estudos de **Lógica de Programação** oferecidos pela [Alura](https://www.alura.com.br/), focado em praticar a manipulação do DOM e estruturação de funções em JavaScript.

## 🔖 Sobre o Projeto

O "Jogo do Número Secreto" desafia o usuário a descobrir qual é o número oculto através de palpites. A cada tentativa incorreta, o sistema fornece dicas valiosas, informando se o número secreto é **maior** ou **menor** que o palpite atual. O jogo também contabiliza o número de tentativas até o acerto!

## 🚀 Tecnologias Utilizadas

O projeto foi criado utilizando as tecnologias base do desenvolvimento web:

* ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) - Estruturação semântica da página.
* ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) - Estilização e layout responsivo.
* ![JavaScript](https://img.shields.io/badge/JavaScript-323330?style=for-the-badge&logo=javascript&logoColor=F7DF1E) - Lógica de programação, geração de números aleatórios e manipulação do DOM.

## ⚙️ Funcionalidades

- [x] Geração de um número aleatório a cada nova partida.
- [x] Leitura do palpite inserido pelo jogador.
- [x] Feedback visual na tela indicando se o número secreto é maior ou menor.
- [x] Contador de tentativas.
- [x] Botão para reiniciar o jogo ao acertar o número.
- [x] Prevenção de repetição de números já sorteados (lógica de array).
